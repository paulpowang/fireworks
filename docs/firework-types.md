# 煙火種類（Shell types）

每一種煙火：真實世界的參考、視覺特徵、模擬方式、關鍵參數。實作在 `src/engine/fireworks.ts` 的 `burst()` / `setPiece()` / finale 函式。

共通約定：
- 長度單位 `U` = 依螢幕縮放的「設計像素」（直式約 1 U ≈ 1 CSS px，橫式依高度）。
- `R` = 目標爆開半徑；初速 = `R × drag`（指數阻力下，最終位移 ≈ v0 / drag）。
- `q` = 依目前品質等級的粒子數倍率（見 engine-notes.md）。
- 拖尾（trail）= 粒子每秒噴出 N 顆短命 ember；ember 是「低優先」粒子，預算用到 85% 就不再生。

## 終章（Finales）

| 終章 | 參考 | 結構 | 預算策略 |
|---|---|---|---|
| 經典終章 | — | 5.5 s 內 34 發主題終章類型 + 7 發收尾齊射 | 一般 |
| 長岡巨型 | 長岡まつり大花火大会 2026 | 底部速射連發（0, 2.6 s）+ 地面火花（5.2 s）；6 發雙芯花束；3 排巨型金/白菊（直式 3 顆、橫式 4 顆，半徑 ≈ min(W/n×0.62, 天空×0.36)），各排 flight 1.2 s → 高潮在 +2.0 s；濃厚被照亮的煙 | 巨型菊 alpha 0.6 / size 1.7 避免 additive 過曝；trail 只有 5/s |
| 大樓秀（只在地標場景） | 台北 101 跨年煙火、Space Needle 跨年 | 全長約 42 s：開場塔尖閃白 + 一發大菊 → 由下往上逐層金色噴泉（1.2–7.4 s，每層同時 mine 銀色）→ 左右輪流的彗星掃射（8.5–16.5 s）→ 各平台地雷 + 塔頂連發（17–25 s）→ 整棟同時噴發 + 外框頻閃（25.5–32 s）→ 皇冠：一圈 9（直）/11（橫）發牡丹圍繞塔頂 + 中央巨型金菊 + 4 發千輪，高潮 34 s → 收尾瀑布：每個側邊點向外下方傾瀉金/銀火花 + 冠菊 + 兩發柳 + 三段連環（35–40 s）→ 40.5 s 最後一閃 | 噴泉/彗星/地雷數都乘 `cascadeBudget()`；emitter rate × max(0.4, q)；實測峰值約 2700 顆（直式、cap 4200） |
| 鳳凰亂舞 | 鴻巣花火大会「Phoenix Frenzy」スターマイン | 畫面中央高而窄的橢圓團塊，由數百個小牡丹幾乎同時爆開組成，高度 ≈ 天空 90%（約畫面 45–55%）；3 波相隔 3 s：橘金 → 粉白 → 藍紅紫；高峰時天空染紫 | `miniBurst`：每團 8 顆、無 flicker、無拖尾、共用 sprite；每波 115 × max(0.5, q) 團 |

- 經典終章：天空／霓虹主題的終章類型池加入三段連環；長岡巨型在第 4.6 s 左右左右各一發三段連環，在巨型金菊之間漣漪般爆開。

Music-sync 用 `Fireworks.finaleClimax(kind)`（經典 7.3 s、長岡 2.0 s、鳳凰 0.5 s、大樓秀短版 5.0 s）把終章高潮對到節拍。

## 從大樓發射的效果（台北 101 / Space Needle 場景）
發射點定義見 engine-notes.md「地標大樓與建築發射點」。全部是原創程式造型，不是參考影片的影像。

| 效果 | 真實參考 | 視覺 | 模擬 / 參數 |
|---|---|---|---|
| 噴泉 gerb（`lmGerb`） | 大樓外牆的 gerb / 火花噴筒 | 由轉角斜向外上方噴出的金白火花扇 | `fountain` emitter，rate 50/s，spread 0.2 rad，life 0.75 s，方向依 `e.ang`（往外上方），收尾時改成往外下方 0.55 rad、life 1.4 s → 像瀑布從平台流下 |
| 彗星 comet（`lmComets`） | 高樓側面的 comet 掃射 | 粗亮彗星由側面射出，帶長尾 | 速度 210–290 U，trail 32/s；左右輪流 = side-to-side |
| 平台地雷 mine（`lmMine`） | 平台上的 mine | 一次噴出一撮向上的彩色星 | 26–34 顆，±0.42 rad 錐形，乘 `cascadeBudget()` |
| 塔頂發射 shell（`lmShell`） | 從樓頂打出的割物 | 從「目標下方最高的發射點」升空、在目標處爆開 | 一般 rocket，起點是建築上的 emitter 而非地面；所有既有煙火類型都可以 |
| 大樓閃爍（`flashBuilding`） | 跨年時整棟外框燈光變色 | 輪廓線與窗帶被染成爆炸色後衰減 | 外框/窗帶 canvas `source-in` 上色後 `lighter` 疊加，強度 `exp(-3.2·dt)` 衰減 |

- **點擊**：點在建築旁邊（距最近發射點 190 U 內、在塔頂以下、在地面以上）→ 從最近發射點朝點擊方向噴（50% 彗星 / 50% 噴泉 + 一顆白彗星，方向保持朝外）；點在塔頂以上或遠處 → 從大樓發射所選的煙火類型到點擊位置。
- **set pieces**：光扇改由塔尖往上扇形噴出；地面火花改成由下往上逐層噴泉。
- **自動秀**：隨機穿插整層噴泉、平台地雷、單側彗星與從大樓發射的煙火，每 50 s 自動跑一次大樓秀。
- **配樂同步**：地標場景的 beat 煙火從大樓發射（仍用音樂時鐘鎖定爆點），35% 機率在爆點同時加一層外牆噴泉；終章用大樓秀短版（約 9 s，高潮 5.0 s）。

## 已移除：瀑布（Niagara）
2026-10-20 移除。原本用一條水平「引信」emitter 在中低空傾瀉閃爍火花簾幕，但在手機畫面上看起來不自然（像一條橫在半空的發光線往下滴，沒有真實瀑布煙火那種依附在地面架子／橋上的尺度感與厚度），所以從類型選單、隨機、自動秀、終章、主題權重、配樂同步（drop 改成整排千輪）全部拿掉，`curtain` emitter 也一起刪除。
