# 煙火種類（Shell types）

每一種煙火：真實世界的參考、視覺特徵、模擬方式、關鍵參數。實作在 `src/engine/fireworks.ts` 的 `burst()` / `setPiece()` / finale 函式。

共通約定：
- 長度單位 `U` = 依螢幕縮放的「設計像素」（直式約 1 U ≈ 1 CSS px，橫式依高度）。
- `R` = 目標爆開半徑；初速 = `R × drag`（指數阻力下，最終位移 ≈ v0 / drag）。
- `q` = 依目前品質等級的粒子數倍率（見 engine-notes.md）。
- 拖尾（trail）= 粒子每秒噴出 N 顆短命 ember；ember 是「低優先」粒子，預算用到 85% 就不再生。

## 終章（Finales）

| 終章 | 參考 | 結構 | 預算策略 |
|---|---|---|---|
| 經典終章 | — | 5.5 s 內 34 發主題終章類型 + 7 發收尾齊射 | 一般 |
| 長岡巨型 | 長岡まつり大花火大会 2026 | 底部速射連發（0, 2.6 s）+ 地面火花（5.2 s）；6 發雙芯花束；3 排巨型金/白菊（直式 3 顆、橫式 4 顆，半徑 ≈ min(W/n×0.62, 天空×0.36)），各排 flight 1.2 s → 高潮在 +2.0 s；濃厚被照亮的煙 | 巨型菊 alpha 0.6 / size 1.7 避免 additive 過曝；trail 只有 5/s |
| 鳳凰亂舞 | 鴻巣花火大会「Phoenix Frenzy」スターマイン | 畫面中央高而窄的橢圓團塊，由數百個小牡丹幾乎同時爆開組成，高度 ≈ 天空 90%（約畫面 45–55%）；3 波相隔 3 s：橘金 → 粉白 → 藍紅紫；高峰時天空染紫 | `miniBurst`：每團 8 顆、無 flicker、無拖尾、共用 sprite；每波 115 × max(0.5, q) 團 |

Music-sync 用 `Fireworks.finaleClimax(kind)`（經典 7.3 s、長岡 2.0 s、鳳凰 0.5 s）把終章高潮對到節拍。
