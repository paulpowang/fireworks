# 開發心得（Lessons）

## 地標大樓場景（2026-10-22）
- **陸地層順序要看煙火從哪裡來**：一般場景火箭從地面後方升起，剪影要蓋在 FX 上面；但從大樓「噴出」的火花必須畫在建築前面，否則看起來像在樓後面。地標場景改成先畫陸地、再 `lighter` 疊 FX。
- **發射點是資料，不是程式**：把每個點存成 `{x, y, ang, tier, role, side}`，大樓秀的「由下往上」「左右輪流」「平台地雷」「塔頂皇冠」都只是對同一張表做不同的篩選/排序，換一棟樓只要重寫造型與發射點，不必改編排。
- **直式要讓天空當主角**：塔頂放在 0.27H，建築佔下方約 57%，爆點集中在塔頂附近與上方；橫式塔頂拉到 0.11H 才不會顯得太小。
- **整棟閃爍用外框 canvas + `source-in`**：比逐窗重畫便宜得多（2 次 blit），而且衰減一個數字就好；沒閃的時候整段跳過。
- **點擊要分兩種意圖**：點在建築旁＝想看大樓噴火（從最近點朝點擊方向噴）；點在天空高處＝想放煙火（從大樓打 shell 到那裡）。用「距最近發射點 190 U 內且低於塔頂」區分，用起來很自然。
- **大量 emitter 一定要吃預算**：側邊 20 幾個點同時噴泉，若不乘 `cascadeBudget()` / q，在 q3（cap 1800）會把主星體擠掉。
- **headless 量 fps 不準**：SwiftShader 的 fps 只有 15–40，比較時看 `render()` 主執行緒時間，且同一 seed、同一個終章。
