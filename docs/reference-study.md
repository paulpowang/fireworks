# 參考影片研究（Reference study）

只記錄描述，不收錄任何他人影片的畫面（參考畫面放在 repo 外的 `reference*/`，已 gitignore）。

## 方法
1. 從影片擷取 5–7 張代表性畫面（爆開瞬間、最大展開、消散、整體構圖）。
2. 做成 contact sheet 一次比較，記錄：形狀（球 / 環 / 臂 / 簾幕）、尺寸佔畫面比例、粒子密度、拖尾長短與粗細、顏色與色序、持續時間、高度位置、是否同時多發、煙與天空的光。
3. 把特徵換成引擎參數（見 `docs/skills/fireworks-reference-to-shell/SKILL.md`）。
4. headless 截圖對照，調到「一眼看得出是哪一種」。

## 場景參考（2026-10-20）
- 鴻巢花火（Konosu 2026）的觀眾視角：底部一排亮著的紅／黃屋台、黑色人群裡的手機光點、地平線上被染成粉紫的低煙帶、整片天空被爆炸顏色洗過 → 小鎮車站與河岸草地的「可受光剪影 + 天空 wash」做法。只參考氛圍，畫面全部是程式畫的原創向量剪影。
- 河岸草地：河堤、太鼓橋、小鳥居與紙燈籠、河面細光紋是一般日本河岸花火大會的常見元素，沒有對應特定影片畫面。
